# Pâte Graphique

Bot Discord massif dédié au culte techno-mystique des Pâtes Graphiques. Le projet combine propagande automatique, musique YouTube persistante, économie avancée, casino complet, mini-jeux (100+), système de whitelist et modération ciblée.

## Démarrage rapide

1. Installez les dépendances (voir [docs/INSTALL.md](docs/INSTALL.md)).
2. Configurez les variables `DISCORD_TOKEN` et `DISCORD_APPLICATION_ID`.
3. Lancez `python bot.py`.

## Structure
```
config/        Phrases, paramètres
modules/       Cogs (propagande, musique, fun, mini-jeux, modération)
economy/       Gestion des Graphique Coins et XP
casino/        Jeux d'argent mystiques
music/         Intégration YouTube + file persistante
database/      Gestion SQLite
utils/         Embeds, checks whitelist
```
